# **App Name**: KopaGuide

## Core Features:

- Firebase Insights: Smart suggestions. Generate tips for making the most of your firebase data and metrics using an AI tool.
- Chart Rendering: Data visualization. Display key Firebase data in charts.
- Dashboard Summary: Show a concise overview of Firebase project performance and metrics at a glance.

## Style Guidelines:

- Primary color: A vibrant blue (#4285F4) to convey trust and intelligence, aligning with the app's utility in data analysis.
- Background color: A light, desaturated blue (#E8F0FE) provides a clean, professional backdrop that doesn't distract from the data visualizations.
- Accent color: A contrasting orange (#F4B400) to highlight important metrics and interactive elements, ensuring key information stands out.
- Clean, sans-serif font.
- Use a consistent set of minimalist icons.
- Emphasize a clean, grid-based layout
